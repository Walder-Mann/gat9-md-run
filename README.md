# Markdown Runner (GAT9) 🚀

Интерактивная среда выполнения PowerShell-скриптов прямо из стандартного встроенного средства предпросмотра **VS Code Markdown Preview** (`Ctrl + Shift + V`). 

Расширение превращает обычные `.md` файлы в удобные автоматизированные интерактивные документы.

## ✨ Основные возможности

* **Запуск в один клик:** Добавляет нативную кнопку `▶` к каждому блоку кода с разметкой `powershell`.
* **Автоматический вывод:** Результат работы команды автоматически вставляется прямо под кодом в блок типа ````text ````.
* **Умное обновление:** При повторном запуске команды старый результат автоматически затирается и обновляется, не загрязняя файл.
* **Поддержка многострочности:** Автоматически обрабатывает символ переноса строки в PowerShell (бэктик `` ` ``).
* **Честный UTF-8 и локализация:** Полная поддержка кириллицы на Windows без кракозябр (включая такие утилиты, как `wsl`, `ping` и другие).
* Запуск скриптов инициализации (powershell init-script), находящихся выше исполняемого кода
* Управление скриптами инициализации через параметры расширения 

## 🚀 Как пользоваться

1. Откройте любой `.md` файл.
2. Создайте блок кода PowerShell:
   ````markdown
   ```powershell
   echo $env:USERNAME
   wsl --list
   ```
   ````

   ```powershell init-script
   $UserName = "Иван"
   $ServerIp = "192.168.1.50"
   ```

   ```powershell
   echo $UserName $ServerIp
   ```

3. Откройте стандартный предпросмотр Markdown с помощью комбинации клавиш **`Ctrl + Shift + V`**.
4. Нажмите кнопку **`▶`** в правом верхнем углу блока кода.
5. Результат мгновенно запишется в исходный файл и отобразится на экране.

## 🛠️ Разработка и обновление

### Тестирование (Отладка)
1. Откройте папку проекта в VS Code.
2. Нажмите **`F5`** для запуска тестового окна (*Extension Development Host*).
3. Создайте `.md` файл в открывшемся окне и тестируйте изменения.

### Сборка локального пакета (`.vsix`)
Для компиляции, минификации и упаковки расширения в один клик выполните в терминале:
```bash
vsce package
```
*Итоговый файл расширения будет весить всего ~10 КБ thanks to `esbuild`!*

### Как обновить установленную версию
1. Внесите правки в код `src/extension.ts`.
2. Поднимите версию в `package.json` (например, с `0.0.1` на `0.0.2`).
3. Запустите `vsce package`.
4. Установите новый `.vsix` файл в свой основной VS Code поверх старого.
